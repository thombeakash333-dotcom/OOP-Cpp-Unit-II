## Brief Description

### 1. Basic Single Inheritance

Demonstrates single inheritance using Person as the base class and Student as the derived class.

### 2. Protected Member Access

Demonstrates how a derived class can access protected members of a base class.

### 3. Public versus Private Inheritance

Demonstrates the difference between public and private inheritance.

### 4. Multilevel Inheritance

Demonstrates inheritance through Person, Employee and Manager classes.

### 5. Hierarchical Inheritance

Demonstrates multiple classes, Car and Bike, inheriting from Vehicle.

### 6. Multiple Inheritance

Demonstrates a Student class inheriting from Academic and Sports classes.

### 7. Multiple-Inheritance Ambiguity

Demonstrates how scope resolution is used to resolve ambiguity between base-class functions.

### 8. Constructor and Destructor Order

Demonstrates the order in which constructors and destructors are executed in inheritance.

### 9. Parameterized Base Constructor

Demonstrates passing parameters from a derived-class constructor to a base-class constructor.

### 10. Function Overriding

Demonstrates function overriding using virtual functions and override.

### 11. Abstract Class

Demonstrates an abstract class using a pure virtual function.

### 12. Virtual Base Class and Diamond Inheritance

Demonstrates virtual inheritance and the diamond inheritance problem.

### 13. Friend Class

Demonstrates how a friend class can access private members of another class.

### 14. Nested Class

Demonstrates a class defined inside another class.

### 15. Vehicle Rental System

Demonstrates inheritance, function overriding and polymorphism using a vehicle rental system.

### 16. Employee Payroll System

Demonstrates abstract classes, inheritance, function overriding and polymorphism using an employee payroll system.
